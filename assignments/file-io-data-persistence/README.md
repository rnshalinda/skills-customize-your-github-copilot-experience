# 📘 Assignment: File I/O and Data Persistence

## 🎯 Objective

Practice reading from and writing to files in Python. Learn how to store program data so it persists between runs.

## 📝 Tasks

### 🛠️ Read and analyze a text file

#### Description
Load a text file and count the number of lines and words it contains.

#### Requirements
Completed program should:

- Open a text file and read its contents.
- Count the total number of lines and total number of words.
- Print the results with clear labels.
- Example output:
  `Total lines: 4`
  `Total words: 18`


### 🛠️ Append journal entries to a file

#### Description
Write a function that saves a journal entry to a file so the entry is preserved for later.

#### Requirements
Completed program should:

- Ask the user for a journal entry.
- Append the entry to a file without overwriting existing content.
- Include the current date or a separator on each new entry.
- Confirm to the user that the entry was saved.


### 🛠️ Save and load settings

#### Description
Create a simple settings file to save user preferences, then load those preferences the next time the program runs.

#### Requirements
Completed program should:

- Prompt the user for at least two preferences (for example, favorite editor and theme).
- Save those preferences to a file.
- Read the file back and display the saved preferences.
- Use file reading and writing so the preferences persist between program runs.
